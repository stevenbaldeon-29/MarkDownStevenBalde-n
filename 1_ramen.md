# Com preparar un bo i ràpid Ramen Instantani
>"Una recepta senzilla i deliciosa per a un àpat ràpid."

Els **fideus orientals** són una opció deliciosa i versàtil que es pot combinar amb una gran varietat d’ingredients, com ara verdures, carn o marisc. Per donar-los un toc especial, pots afegir-hi el teu *topping* preferit i crear un plat ple de sabor i personalitat.

## Ingredients
- Fideus orientals
- Brou de pollastre o de verdures
- 2 ous
- Pollastre o porc
- Ceba tendra
- Pastanaga
- Xampinyons
- All
- Gingebre
- Salsa de soja
- Oli de sèsam

## Passos

- [x] Prepara el brou: escalfa el brou en una olla i afegeix-hi l’all, el gingebre i una mica de salsa de soja.

- [ ] Cuina els ingredients: talla el pollastre i les verdures a trossos petits i cuina’ls en una paella.

- [ ] Bull els fideus: segueix les instruccions del paquet i escorre’ls.

- [ ] Prepara els ous: bull-los durant uns 7-9 minuts i pela’ls.

- [ ] Munta el ramen: posa els fideus en un bol, afegeix-hi el brou calent, el pollastre i les verdures.

- [ ] Afegeix el topping: decora-ho amb l’ou tallat per la meitat, la ceba tendra i les llavors de sèsam.
